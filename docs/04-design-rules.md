# 04. 디자인 규칙

디자인 SSOT는 Penpot이다. 원본 파일·현재 보드·적용 경로는 [design/README.md](../design/README.md), 작성·편집·검수 절차는 [DESIGN.md](../DESIGN.md)를 따른다. 이 문서에 같은 규칙·보드 목록을 중복 작성하지 않는다.

- 작업 전 연결된 파일 ID와 현재 채택본을 확인한다. 로컬 캡처·이전 시안을 원본 대신 사용하지 않는다.
- 원본의 공통 색상·타입·컴포넌트·상태를 재사용한다. UI 문구는 네이티브 Text로 유지한다.
- 구현은 `src/shared/ui/themes/`, `src/shared/ui/icons/`, `assets/fonts/`와 해당 화면의 기존 소유자를 먼저 확인한다. A 버튼의 디자인 채택을 게임 적용 완료로 취급하지 않는다.
- 디자인 수정은 편집 가능한 원본과 원본·적용 경로 안내에 함께 반영한다. 로컬 보관은 [개발 규칙](02-development-rules.md#에셋-관리와-보관-범위)을 따른다.
- 제품의 지원 언어·기기·접근성 목표는 [PRODUCT.md](../PRODUCT.md)의 Notion 원문을 따른다. Cafe24 PRO UP 지정이 모든 언어의 글리프 지원을 보장하지 않으며 대체 폰트·번역·긴 문구는 별도 검수한다.
