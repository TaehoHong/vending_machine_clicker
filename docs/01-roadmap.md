# 01. 로드맵·역량 맵

제품 범위·우선순위의 SSOT는 Notion이다. 아래는 구현 소유권과 후속 기획 위치를 찾는 색인이다. 날짜·콘텐츠 수·밸런스를 새로 확정하지 않는다.

## 단계

1. 현재 게임을 바탕으로 Notion의 첫 출시 반복과 출시 품질 기준을 충족한다.
2. Windows Steam 출시 준비에 로컬 저장 호환·Steam Cloud·다국어·접근성 목표를 포함한다.
3. 모바일은 후속 단계로 다루고 별도 진행·계정·저장 경계를 적용한다.

단계별 일정·릴리스 수·출시 가격은 미확정이다. 멀티플레이·채팅·거래·광고·인앱결제·분석 수집은 첫 버전 제외다. 구체적인 기능 상태 머신·권한·데이터 필드·구현 순서는 `deferred-to-feature-planning`이다.
