# Penpot 게임 화면·에셋 전체 적용

## 승인·범위

사용자의 원본 전체 적용 요청이 구현 승인이다. 앞선 카드 범위로 전체 적용을 제한하지 않는다. 원본 파일 cd444aaf-0d8c-801b-8008-cda246e18650을 실제 편집 화면과 다운로드한 .penpot 파일로 확인했다. 원본 전체는 임시 폴더에서 분석하고 게임에서 쓰는 에셋·씬만 저장한다.

2026-10-27 사용자 확정: 위치 검토·작성 중 시설 화면도 원본 그대로 포함한다. 시설은 이후 사용자 확정한 실제 수치로 구매·생산까지 연결한다. 타이틀, 플레이/HUD/목표, 음료·능력, 일시정지/저장, 설정, 시설 구매/관리/강화/보상/미리보기와 수색·구매·피버·손님 에셋을 포함한다.

스테이지별 자판기·상품 구성을 고려하되 현재 카탈로그 인덱스·저장 계약을 보존한다. 원본에 없는 배정과 전환은 생성하지 않는다. 다른 작업의 DESIGN.md와 .DS_Store 변경을 보존한다.

## 기존 소유자·파일 경계

- owner-found: main_menu, play, drinks, pause, play/effects의 표현·입력, game_session과 progression/economy 규칙·차감, progress_store 저장.
- owner-found: shared/ui/themes/play_theme.tres, pixel_button.gd, drink_catalog.DATA. 공통 테마와 실제 Penpot 컴포넌트를 재사용한다.
- owner-absent: 설정·시설 화면. 실제 화면만 features/settings, facilities에 추가해 app/Play에서 연결하며 UI에서 생산 규칙을 만들지 않는다.
- 임시 추출기로 실제 사용하는 그래픽과 네이티브 씬만 가져온다. 전체 .penpot·검수 캡처·임시 추출기는 저장소에 복제하지 않는다. 이전 build_scenes.py는 사용하지 않는다.
- owner-absent: game/automation/facility_rules.gd는 UI와 분리한 시설 규칙, integrations/settings/preferences_store.gd는 진행 저장과 분리한 기기 설정 소유자다.
- facilities/facility_world.gd는 설치 그림·수령 입력·손님 생성, effects/customer_rig.gd는 원본 파츠의 관절 표현, data/customer_poses.gd는 추출된 파츠·회전 중심 정의를 소유한다. Play에는 화면 연결과 저장 요청만 둔다.
- shared/ui/design_view.gd는 여러 화면에서 원본 메타데이터 조회·기존 pixel_button 상태 연결·화면/숫자 fit을 공유한다. 기존 테마·폰트·금액 변환을 재사용한다.

## 확정·원본 동기화

- 자동 자판기: 빈캔 10개 해금, 1,000 Gold 구매, 10초마다 10 Gold. 20%로 빈캔 1개 드롭, 15초 후 소멸.
