# 메모지 HUD와 퀘스트 목록 적용

## 현재 계약 · 구현 승인

사용자가 선택한 고양이와 스프식 목록 배치와 메모지 아이콘 시안을 게임에 적용한다. 현재 상시 목표 패널·순차 수령을 메모지 HUD·독립 행 수령으로 바꾼다. 사용자의 “이제 퀘스트 UI랑 20초 달성 알림, 골드 보상 애니메이션까지 게임에 적용해”를 이 계약의 구현 승인으로 기록한다.

### 관찰 가능한 완료 조건

- 추가 사용자 확정: 달성 시 중앙 상단에 퀘스트 이름·종류, 보상·받기 버튼의 전체 카드를 20초 표시한다. 접는 단계는 없으며 수령하면 즉시 사라진다. 알림이 사라져도 보상은 목록에 남는다.
- 골드 수령 시 상단 카드 위치에서 대량 폭발 → 바닥 낙하·대기 → 왼쪽 상단 골드 HUD 흡입을 재생한다. 보상 재화 기준이며 빈캔 수집 목표의 골드 보상에도 골드를 사용한다. 수색·시설 보상과 시각적으로 구별하기 위한 별도 제한은 두지 않는다. 동전 개수·구간별 시간은 조정 대상이며 20~40개·2~3초 제안을 확정 수치로 취급하지 않는다.

- 우상단 54.4×54.4 메모지 버튼으로 목록을 연다. 상시 글자·진행 숫자는 없으며 미수령 보상이 있을 때만 작은 골드 점을 표시한다. 달성만으로 목록창을 자동으로 열지 않는다.
- 별도 수락 없이 두 목표를 계속 집계한다. 목록의 목표·진행·보상과 진행 중/받기/수령 완료 상태를 원본대로 표시한다.
- 각 행의 보상을 다른 행의 수령 여부와 관계없이 수동 수령한다. 보상은 한 번만 지급하고 즉시 저장하며 목록과 행 위치를 유지한다.
- 획득 누적 기준으로 빈캔 목표를 계산하여 시설분 중복과 소비 후 진행 감소를 막는다. 기존 음료·시설 누적 값과 이전 저장의 보유량 fallback을 재사용한다.
- X/ESC로 닫고 열기 버튼으로 포커스를 돌려준다. 모달 배경 입력과 피버 시간을 차단한다. 시설 생산은 기존 정보창과 같은 방식으로 계속한다.
- 기존 두 목표·임시 수치(동전 10회/5,000 Gold, 빈캔 5개/100 Gold), 저장 키·기본값을 유지한다. 기존 저장의 달성·수령 상태를 복원한다.
