# 손님 동작별 프레임 애니메이션

## 범위·승인

사용자가 2D 애니메이션 기법을 조사·적용하고 걷기 / 뒤돌아 조작 / 줍기를 별도 동작으로 나누라고 지시했다. 기존 관절 보간 선택을 이 최신 지시로 대체한다. 몸·팔의 회전 보간과 메시 시제품은 채택하지 않는다.

## 근거·소유자

- owner-found: customer_rig.gd는 손님 표현, customer_flow.gd는 시설 타이머에 맞춘 등장·이용·퇴장이다. 새 게임 규칙·보상 소유자를 만들지 않는다.
- Penpot cd444aaf-0d8c-801b-8008-cda246e18650의 02 에셋, `캐릭터 / 손님 01 / 측면 보행·후면 이용`과 `손님 동작 / 01..30`의 원본 프레임을 사용한다. 원본의 공통 192×248 캔버스·발밑 기준을 유지한다.
- Godot 공식 `2D sprite animation`과 `Using AnimationTree`를 확인했다. 프레임 교체에는 AnimatedSprite2D/SpriteFrames를 사용한다. 이 경로에는 관절·메시 블렌딩이나 범용 AnimationTree가 필요하지 않다.
- customer_rig.gd를 customer_animation.gd로 교체하고 전용 SpriteFrames 리소스를 같은 effects 폴더에 둔다. 독립 데이터인 관절 좌표와 더 이상 사용하지 않는 이번 작업의 파츠 PNG는 제거한다. Penpot 편집 원본은 보존한다.

- [ ] 걷기 → 방향 전환 → 조작 → 복귀 → 줍기 → 들고 퇴장을 별도 클립으로 재생.
- [ ] 생산 시점과 수령 시점을 유지하고 부가 회전·가로 찌그러뜨리기 제거.

- [ ] 실제 게임 주기를 재생하고 동작 전체를 영상·연속 프레임으로 확인.
