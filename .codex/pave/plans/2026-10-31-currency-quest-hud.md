# 재화 디자인 통일 · 퀘스트 상시 HUD

2026-10-31 사용자가 설명한 수정안의 구현과 Penpot·Notion 반영을 명시 승인했다. 코인·빈캔은 기존 재화 HUD 원본으로 통일하고 금액별 색상·보상·저장 규칙을 유지한다. 빈캔 호버를 제거하고 메모지 버튼·목록창을 두 줄 상시 진행·독립 받기·완료 표시로 교체한다. 중앙 20초 알림·보상 연출은 유지한다. 남은 제품 결정은 없다.

## 소유자·품질 검사

- `owner-found`: `shared/ui/icons`, Penpot Currency 원본, search_coin·coin_insert_fx를 재사용한다. 아이콘·호출자·관련 회귀를 대조했다. 네 개 공통 코인 SVG는 같은 원본의 기존 금액별 색상 변형이며 can_icon.svg는 공통 빈캔 원본 내보내기로 교체했다.
- `owner-found`: `game_session.quest_status/claim_quest` → Play → app의 집계·수령·저장을 유지한다. UI는 재화를 직접 지급하지 않는다.
- 기존 quest_screen 표시 책임은 quest_hud.gd로 전환했다. 새 hud_row_design.tscn은 두 목표가 실제 재사용하는 작은 행이다. 기존 modal 전용 씬·스크립트와 변경으로 생긴 미사용 리소스를 제거했다.
- 디자인은 `docs/04-design-rules.md`, 기존 QuestRow·InfoTitle·InfoBody·PixelButton·play_theme와 Penpot 공통 색·글자 스타일을 재사용한다. 새 테마나 범용 기반 계층은 추가하지 않는다.

## 검증 근거·테스트 가치

상시 진행 미표시로 quest_screen_test의 변경 전 exit 1을 확인한 후 변경 후 exit 0·0 failures를 확인했다. 기존 실제 입력 테스트를 갱신하여 보상 접근 소실·중복 지급·모달 오작동·resize 입력 불일치를 보호한다. 시설·구매 영역 검증은 빈캔 hover 미표시와 기존 수령·골드 tooltip을 확인한다. 외형은 중복 정적 문자열 테스트 대신 실제 리소스 연결과 렌더링으로 검수한다.

`/private/tmp/currency-quest-verification/results.json`의 21개 회귀는 모두 passed=true다. 실제 Metal 렌더링에서 진행·수령 가능·완료와 시설·음료 해금의 재화 그림을 확인했고 받기 글자 대비를 수정해 재검수했다. 저장 스키마·가격·목표/보상·새 퀘스트는 변경하지 않는다.

검증된 코드는 작업 브랜치에서 커밋한 뒤 로컬 main에 머지한다. 외부 디자인 대기는 숨기지 않으며 push·PR은 수행하지 않는다.
