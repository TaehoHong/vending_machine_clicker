**현재 Penpot 29개 화면·상태를 Impeccable의 critique 방식으로 리뷰했습니다. 픽셀 아트와 공통 HUD의 시각적 방향은 일관되지만, 행동 위치와 상태 변화 전달에 개선이 필요합니다.** 다음 스테이지·지역 이동은 평가 범위에서 제외했습니다.

**디자인의 개성과 강점**

골목 배경, 붉은 자판기, 파란 픽셀 UI, Cafe24 서체가 게임의 정체성을 만듭니다. 일반적인 앱 스타일로 바꿀 이유는 없습니다. 중앙 자판기가 시선을 잡고 HUD가 주변을 받치는 구도, 버튼·패널·비활성 상태의 공통 표현, 성장 결과를 보여 주는 능력 획득 토스트와 휴식감을 주는 일시정지 문구가 잘 작동합니다.

**우선 수정할 5가지**

1. **[P1] 동시 피버인데 한 피버만 보입니다.** `피버 동시 활성` 보드는 PUNCH FEVER·5.0s·GOLD ×3만 표시하고 SEARCH FEVER 상태와 남은 시간은 보여 주지 않습니다. 유저가 수색 효과가 끝났다고 오해할 수 있습니다. 공통 HUD 안에 두 피버를 별도 행으로 표시하고 각각 남은 시간을 보여 주세요. 실제 게임 효과가 사라진다는 판정은 아닙니다. 권장 작업: `impeccable clarify`.
2. **[P1] 첫 수색의 클릭 위치가 모호합니다.** 기본 플레이에서 바닥 화살표만으로는 자판기 밑을 클릭해 동전을 찾는 행동을 알아내기 어렵습니다. 명확한 가격 버튼과 달리 수색에는 행동명과 결과 단서가 없습니다. 첫 수색 전까지 `자판기 밑을 클릭해 동전 찾기` 같은 짧은 안내를 표시하고 발견 후 없애는 방식이 적절합니다. 가격 버튼의 금액 중심 표기는 유지합니다. 초보자 혼란은 화면 근거에 따른 추론이며 사용자 테스트 결과는 아닙니다. 권장 작업: `impeccable onboard`.
3. **[P2] 음료의 잠금·획득·추가 가능 상태를 선택 전에 구분하기 어렵습니다.** 초기 음료 화면의 15개 슬롯이 비슷한 밝기로 보여 개별 선택과 기억에 의존하게 됩니다. 슬롯에 작은 잠금·체크 표시를 붙이고 상세 패널에서 조건을 설명하세요. `빈캔 2`인 부족 상태에서는 `5개로 추가` 버튼 옆에 `빈캔 3개 부족`을 표시하면 판단이 빨라집니다. 확정된 5×3 배열은 유지하고 비용 배지를 슬롯마다 다시 넣을 필요는 없습니다. 권장 작업: `impeccable clarify`.
4. **[P2] 같은 재화가 Gold·G·¥로 표시됩니다.** 지갑의 `1,250 Gold`, 가격의 `100 G`, 퀘스트의 `¥5000`이 함께 있어 서로 다른 재화처럼 읽힐 수 있습니다. 숫자·구분자·단위 또는 공통 재화 아이콘의 규칙을 정하고 지갑·가격·퀘스트 보상에 일관되게 적용하세요. 가격 버튼은 금액 중심 표현을 유지합니다. 권장 작업: `impeccable polish`.
5. **[P2] 부족 안내는 행동과 멀고, 저장 실패의 복구 행동은 불명확합니다.** Gold 부족 문구는 화면 아래 바닥 위 14px 텍스트여서 자판기의 가격 버튼과 연결해 읽기 어렵습니다. 부족액을 가격 근처의 공통 패널에 표시하세요. 저장 실패는 `다시 시도해주세요`만 쓰기보다 재시도할 버튼을 명시해야 합니다. 저장 실패 후 종료 시 문구는 실제 저장 동작을 확인한 뒤 확정해야 합니다. 권장 작업: `impeccable harden`.

**인지 부담과 사용자 관점**

플레이 화면의 기본 부담은 낮고 음료 선택 화면은 중간 수준입니다. 15개 선택지 자체보다 각 상태를 기억해야 하는 점이 문제입니다. 타이틀의 호기심과 보상·피버의 고조는 잘 이어지지만, 첫 수색과 저장 실패에서 흐름이 끊길 수 있습니다.

- **Jordan · 처음 플레이하는 사람:** 바닥 화살표가 가리키는 행동과 음료 중 지금 가능한 선택을 쉽게 알아내기 어렵습니다.
- **Sam · 작은 글씨와 정보 비교에 부담을 느끼는 사람:** 비슷한 음료 슬롯, 멀리 떨어진 보유량과 비용, 바닥 위 작은 부족 문구를 함께 비교해야 합니다.
- **Riley · 여러 상태를 확인하는 사람:** 동시 피버의 각각 남은 시간과 저장 실패 후 재시도 경로를 확신하기 어렵습니다.

이는 화면 기반의 점검이며 실제 사용자 관찰 결과는 아닙니다.

**작은 개선점과 검증 범위**

퀘스트 패널의 큰 빈 영역, 능력 요약의 정보 묶음, 타이틀 영어 메뉴와 플레이 한국어의 혼용은 후순위로 다듬을 수 있습니다. 픽셀 서체를 교체하거나 이미 확정한 음료 배열을 줄일 근거는 없습니다.

자동 검사는 SVG 3개에서 0건을 보고했지만, 검사기의 HTML/CSS 중심 규칙은 Penpot·Godot의 상태·텍스트·상호작용을 충분히 검사하지 못합니다. 따라서 자동 검사 통과를 UI 품질이나 접근성 통과로 보지 않았습니다. 외곽선이 글자 대비에 영향을 주므로 채움색만으로 전체 대비 실패를 판정하지도 않았습니다. 실제 게임의 키보드 조작·애니메이션·성능·저장 동작은 이번 리뷰에서 검증하지 않았습니다.

리뷰 제안은 아직 확정된 디자인 규칙이 아닙니다. 이번 작업에서는 디자인과 게임 코드를 변경하지 않았습니다.
