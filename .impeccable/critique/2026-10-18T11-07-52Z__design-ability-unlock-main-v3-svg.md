# 능력 해금 화면 · Cafe24 적용 후 재리뷰

실제 Penpot에서 내보낸 `main-cafe24-penpot.png`, `states-cafe24-penpot.png`와 기존 B 자판기를 비교했다. 디자인 수정은 수행하지 않았다.

## 총평과 디자인 고유성

Astra의 판단은 B의 외장·깊이·마모와 커진 음료가 자연스럽게 결합됐으며, 이제 이 게임을 위해 만든 자판기 화면으로 보인다는 것이다. 용기 비례는 해결됐고 선택 표시는 대부분 해결됐다. LCD의 정보 구분도 개선됐으나 작은 글자의 가독성과 상태 의미 전달은 남아 있다. 승인 음료는 본체보다 부드러운 그림체지만 상품 샘플로 식별할 수 있어 현재 조합은 수용 가능하다.

## 잘된 점

- 진열창이 중심이고 설명이 본체 안에 모여 시선이 분산되지 않는다.
- 큰 병·캔·작은 병의 비례가 자연스러워졌으며 미획득 음료도 식별된다.
- 노란 선택 명찰과 문구가 LCD 대상에 연결되고 현재 누적 효과와 획득 횟수를 구분한다.

## 우선순위

1. **[P1] 작은 상품명과 설명의 획이 조밀하다.** 상품명 15개 중 13개는 12px, 긴 두 이름은 11.5px다. LCD 보조 글자와 상태 보드 주석도 주시가 필요하다. Cafe24 PRO UP은 유지하며 글자 크기·간격과 명판 여유를 늘린다. 긴 상품명은 진열용 짧은 이름과 LCD의 전체 이름으로 나누는 방향을 검토한다. 잘림은 발견되지 않았으며 글꼴 적용 실패가 아닌 판독성 문제다. Suggested command: `$impeccable typeset`.
2. **[P2] 잠금·체크·8/15의 뜻이 메인에 부족하다.** 체크가 획득인지 최대 강화인지, 숫자가 무엇을 세는지 명시되지 않는다. 표시창에 ‘획득 종류’를 붙이고 선택 음료의 LCD에 ‘미획득’·‘최대 강화’를 명시한다. Suggested command: `$impeccable clarify`.
3. **[P2] ‘능력 해금’ 제목은 이 화면에서 해금하는 곳처럼 읽힌다.** 실제 목적은 능력 조회다. ‘음료 구매 성공 시 능력이 해금됩니다’ 안내를 추가하거나 조회 목적의 제목을 검토한다. 구매·사용 버튼을 추가할 필요는 없다. Suggested command: `$impeccable clarify`.
4. **[P3] 상품 버튼은 본체에 비해 얇고 평평하다.** 버튼의 윗면 반사·아랫면 그림자와 누름 면 두께를 보강하면 본체 재질과 이어진다. 실제 클릭 영역 크기는 평가하지 않았다. Suggested command: `$impeccable polish`.

## 인지부하·사용자 관점

상품 찾기는 낮은 부담, 상태 해석은 중간 부담이다. 15개 선택지는 수집 진열 구조에 맞으며, 4개가 넘는다는 이유로 숨길 필요는 없다. 초보자는 이 화면에서 해금하는지와 체크의 의미에서 멈출 수 있다. 저시력자는 작은 상품명·잠금·체크의 구별이 어렵다. 첫인상에서 느끼는 풍부한 진열이 설명을 읽는 단계까지 이어지도록 작은 글자와 상태 안내를 우선 보완한다.

## 독립 검사와 한계

CLI detector는 SVG 두 개를 대상으로 1회 실행해 `[]`, finding 0개, 종료 코드 0을 반환했다. SVG 전용 레이아웃 검사기가 없어 무결점 판정으로 사용하지 않았다. 독립 B의 실제 PNG·소스 검사에서도 작은 상품명 주의점을 확인했다. B는 P2 가독성 주의점으로 평가했고 Astra는 우선 수정할 P1로 평가했다. 최종 우선순위는 Astra의 사용성 판단을 따르되 판독 불가·기능 차단으로 확대하지 않는다.

소스 40개 텍스트의 Cafe24 PRO UP / 400 지정은 일치하고 로컬 TTF 측정에서 폭 초과는 0개다. 실제 네이티브 PNG에서도 글자 잘림은 발견하지 못했다. 자동 검사 false positive는 없었다. 대비·클릭 영역·ESC 실제 작동·키보드 탐색·상태 전환·게임 구현은 검증하지 않았다. 브라우저/Computer Use는 사용자 지시와 정적 산출물 범위에 따라 사용하지 않았다. 수치와 진행도는 예시다.
