# 자판기 클릭커 · 화면·상태·모션 구상

상태: 구상을 먼저 정리한 뒤 Penpot v3에 제작 완료. 사용자 최종 승인을 의미하지 않는다. 결과와 검수 범위는 `../DESIGN.md`에 기록했다.

## 이번 수정의 기준

사용자 피드백: 이전 시안은 게임 화면보다 일러스트처럼 보였다. 실제 게임 UI 레퍼런스를 조사하고, 어떤 화면을 만들지와 각 화면의 정보·상태·애니메이션을 먼저 구상한 뒤 제작한다.

핵심 순환은 동전 줍기 → 물품 뽑기 → 사용·수집 → 능력 강화 → 자동 자판기 설치다. 상품 판매 사업, 고객 수요 조절 등 레퍼런스 게임의 다른 규칙을 가져오지 않는다.

## 화면 지도

시작 → 메인 플레이
메인 플레이 ↔ 구매 / 수집함 / 능력 강화 / 자동화 설치
구매 → 획득 결과 → 사용 / 보관 / 다시 뽑기
메인 플레이 ↔ 일시정지 → 시작

### 시작

- 게임명과 작은 자판기 오브젝트, 이어하기·새 게임·설정.
- 이어하기를 가장 크게 보여준다. 저장이 없는 상태에서는 새 게임이 주 동작이다.
- 큰 배경 그림으로 게임 규칙을 가리지 않는다.

### 메인 플레이

- 상단 HUD: 골드, 빈캔, 자동 수익, 현재 골목/자판기 레벨.
- 왼쪽 플레이 공간: 픽셀 자판기, 기계 아래 넓은 클릭 영역, 클릭 진행 칸, 동전 획득 효과.
- 자동 자판기에서 떨어진 물품은 회수 가능 표시와 남은 시간을 보여준다.
- 오른쪽 고정 패널: 구매·강화·자동화·수집 전환. 패널을 바꿔도 자판기와 클릭 위치는 유지한다.
- 하단: 보유 물품 퀵슬롯과 자동 자판기 설치 자리.
- 확인할 상태: 첫 진입, 클릭 중, 동전 획득, 자동 수익, 회수할 물품 있음.

### 자판기 구매

- 물품 아이콘, 이름, 보유 수량, 가격, 알려진 효과, 꽝 안내.
- 구매 가능·골드 부족·해금 전을 색상과 문구로 구분한다.
- 뽑기 비용을 주 버튼 안에 표시한다. 상세 선택 중에도 자판기 장면이 보인다.

### 획득 결과

- 결과 물품을 크게 표시하고 보유 수량 변화를 보여준다.
- 사용 가능한 물품: 바로 사용·보관. 반복 구매: 다시 뽑기.
- 꽝: 실패를 분명하게 알리되 성공 보상이나 능력 상승을 표시하지 않는다.
- 음료를 실제로 사용한 후에만 빈캔과 능력 변화가 발생한다.

### 수집함

- 음료·라면·잡지·피자·피규어 분류, 보유 수량, 미발견 실루엣.
- 선택한 물품의 효과와 사용 버튼. 수집 여부와 사용 가능한 수량을 구분한다.
- 빈 상태에서는 첫 물품을 얻는 경로를 안내한다.

### 능력 강화

- 클릭, 쓰레기통, 자동 자판기 세 계열.
- 현재 효과 → 다음 효과, 비용, 강화 가능 여부를 같은 행에 표시한다.
- 클릭 횟수 감소·상위 골드 확률·물품 자동 회수·자동 생산량/시간을 구분한다.
- 확정되지 않은 수치와 비용은 시안 예시다. 물 효과의 구체적 수치는 만들지 않는다.

### 자동화 설치

- 설치 가능한 자리, 보유 자판기, 물품 수집 조건, 구매 비용.
- 설치 후 생산 주기·다음 수익·떨어진 물품 회수 상황.
- 쓰레기통은 확률 회수 장치이며 무조건 자동 획득처럼 표시하지 않는다.

### 일시정지

- 계속하기·음향·타이틀로 이동.
- 화면에서 나가더라도 배치나 기록이 즉시 삭제되는 조작을 넣지 않는다.

## 모션 설계

| 동작 | 순서와 시간 | 플레이 규칙 |
|---|---|---|
| 클릭 | 80ms 눌림 → 진행 칸 즉시 증가 → 180ms 동전 등장 → 300ms HUD 이동 | 입력 피드백은 100ms 이내. 연속 클릭을 막지 않는다. |
| 물품 뽑기 | 점등 100ms → 기계 반응 240ms → 배출구 160ms → 결과 180ms | 반복 시 연출 건너뛰기. 실제 결과가 정해지기 전에 성공을 표시하지 않는다. |
| 물품 사용 | 사용 동작 240ms → 효과 변화 200ms → 빈캔 이동 240ms | 음료 사용과 빈캔 전환을 인과 순서로 보여준다. |
| 강화 | 비용 차감 → 레벨/효과 변경 → 240ms 강조 | 현재와 다음 효과가 뒤섞이지 않는다. |
| 자동 생산 | 실제 남은 시간에 맞춘 선형 막대 → 회수 상태 강조 | 거짓 진행률을 보여주지 않는다. |
| 떨어진 물품 | 약한 준비 강조 → 소멸 전 남은 시간 → 회수 시 HUD 이동 | 클릭 영역은 충분히 크고 다른 주 버튼을 가리지 않는다. |
| 패널 전환 | 180–220ms 같은 자리에서 전환 | 플레이 공간과 주요 조작 위치를 유지한다. |
| 일시정지 | 160ms 배경 어둡게, 메뉴 표시 | 나가는 길을 항상 표시한다. |

모션 줄이기에서는 흔들림·입자를 제거하고 짧은 페이드와 즉시 상태 갱신을 사용한다. 정적 Penpot 보드에는 전후 상태와 인터랙션 연결을 표현하며, 타이머와 물리 동작이 구현됐다고 주장하지 않는다.

## 시각 방향

- PC 1600×900 기준. 상단 재화 HUD, 왼쪽 조작 장면, 오른쪽 고정 패널.
- 픽셀 자판기·캔·동전·타일 바닥을 편집 가능한 도형으로 구성한다.
- 짙은 남색 프레임, 밝은 본문, 골드 재화, 민트 보조 동작. 구매와 비활성 상태를 뚜렷하게 구분한다.
- 4px 단위, 3–4px 외곽선, 얕은 버튼 베벨. 얇은 웹 폰트와 부드러운 카드 그리드를 주 구조로 쓰지 않는다.
- 현재 값·비용·남은 시간은 정렬된 숫자 영역에 표시한다.
- 모바일은 48px 이상 핵심 터치 영역과 8px 간격을 확보하고, 화면 조작 위에 패널을 겹쳐 두지 않는다.

## 제작 순서와 검증

1. 메인 플레이: 5초 안에 현재 돈·클릭 위치·다음 구매 비용을 찾을 수 있는가.
2. 구매·획득: 성공/꽝, 사용/보관, 비용과 결과가 구분되는가.
3. 수집·강화: 보유 수량과 전후 효과, 골드 부족·해금 전이 읽히는가.
4. 자동화: 설치와 생산·물품 회수의 관계가 보이는가.
5. 시작·일시정지와 모바일: 복귀 경로와 터치 영역이 명확한가.

기존 Penpot 시안과 다른 사용자의 페이지는 보존하고 새 페이지에서 제작한다. 가격·확률·시간·해금 수량은 게임 밸런스가 확정되기 전까지 예시다.
