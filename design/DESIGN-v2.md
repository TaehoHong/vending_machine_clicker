## 화면 원칙

골목 전체가 플레이 공간이다. 웹사이트형 헤더와 좌우 콘텐츠 분할 대신 배경 위에 게임 HUD를 놓는다. 동전 클릭 영역과 획득 효과가 자판기 아래에 보이고, 보유 골드·빈캔·가방·자동 자판기 수익·다음 설치 해금을 함께 읽을 수 있다. 음료 구매는 배경을 어둡게 한 게임 내 선택 창으로 표현한다.

배경은 ImageGen으로 만든 정적 일러스트다. 버튼·캔·동전·HUD·문구는 Penpot에서 개별 편집 가능하다. 모바일에서는 같은 배경을 1125×844로 유지한 채 x=-480에서 390×844 보드로 클리핑해 자판기 비율을 보존한다. 동전 묶음·클릭 영역 링·포인터·획득 보상은 80px 내려 자판기 앞 바닥에 놓았다. 동전 찾기 진행 표시의 y는 544px, 글자의 y는 550px이다.

## 프로토타입과 한계

PC의 ‘음료 고르기’ 버튼에서 구매 화면으로 이동하고, 구매 화면의 닫기 영역에서 메인 화면으로 돌아가는 연결을 만들었다. 나머지 UI는 정적인 게임 화면 시안이다. 실제 클릭·골드 계산·구매 로직은 구현하지 않았다.

골드, 가격, 수집량, 시간, 해금 수량은 시안용 예시다. 제품명 ‘골목 자판기’는 이름 제안이다. 확정되지 않은 물 효과의 수치는 만들어 넣지 않았다.

## 검수 자료

- `design/review/gameplay.png`: PC 게임 화면 Penpot PNG 내보내기.
- `design/review/mobile-gameplay-editor.png`: 배경 비율과 바닥 위 동전 배치 수정 후 모바일 보드 전체.
- `design/review/purchase-editor.png`: 닫기 글자 수정 후 구매 보드 전체.
- `design/assets/vending-alley.prompt.txt`: 배경 생성 프롬프트. 이미지 내부에도 같은 프롬프트를 기록했다.

완료 검수에서 지적된 모바일 동전 배치를 수정하고 재검수 판정 **“Resolved — ship”**을 받았다. PC 플레이·구매 화면은 앞선 검수에서 콘셉트 화면 범위로 준비 완료 판정을 받았다. 검증 범위는 위 정적 이미지의 구도·HUD 가독성·배경 비율·동전의 바닥 배치·닫기 글자 표시다. 실제 게임 동작, 터치 사용성, 반응형 구현은 검증하지 않았다. 네이티브 Penpot 시안이므로 웹 UI 탐지기는 실행하지 않았다.

MCP는 사용자가 승인한 일시적 연결로 사용했다. 인증 키는 작업 파일과 영구 설정에 저장하지 않았다. 최종 두 UI 수정은 MCP 브라우저 일시 중단으로 Penpot 편집기에서 직접 수행했다.
