# Backstreet Clicker UI 디자인

1152 × 648 PC 화면 기준의 디자인 시안입니다.
현재 게임의 골목 배경과 음료 그림을 사용하고, 어두운 패널·금색 액션 버튼·음료별 포인트 색으로 통일했습니다.

## 파일

- `01-main-menu.svg`: New Game / Load Game / Settings / Exit
- `02-gameplay.svg`: 보유 금액, 음료 수집, 퀘스트, 100엔 투입구 안내, 수색 진행
- `03-water-result.svg`: 큰 물 그림과 수색 숙련도 설명
- `04-green-tea-result.svg`: 큰 녹차 그림과 발견 금액 증가 설명
- `05-pause-menu.svg`: 계속 / 저장 / 끝내기
- 각 SVG와 같은 이름의 PNG: 화면 미리보기
- `overview.png`: 전체 시안 모음
- `tokens.json`: 색상, 간격, 글자 크기, 모서리 규격
- `build_design.py`: SVG 생성 원본

SVG는 배경 이미지를 포함하고 있어 별도 이미지 경로 없이 열 수 있습니다.
텍스트와 UI 도형은 벡터이며, Penpot 캔버스로 SVG를 가져와 편집할 수 있습니다.
한글 글꼴은 Malgun Gothic입니다. 다른 환경에서 글꼴이 없으면 한글 글꼴로 교체해주세요.

## 동작과 상태

- New Game: 기존 진행 백업 후 새 게임. Load Game: 기존 저장 복원.
- 예시 금액·수집 개수·퀘스트 진행은 시연용 값입니다. 실제 UI 구현에서는 저장된 값과 연결해야 합니다.
- 저장이 없으면 Load Game은 비활성화합니다.
- 퀘스트 보상을 모두 받으면 패널을 작은 완료 표시로 접습니다.
- 투입구는 100엔이 있을 때 클릭 즉시 차감하고 애니메이션 뒤 음료 결과를 표시합니다.
- 잔액 부족 시 차감 없이 부족 금액을 안내합니다.
- 물과 녹차는 각각 50% 확률이며, 효과 설명은 현재 게임 규칙과 맞췄습니다.
- 일시 정지: 계속 / 저장 / 저장 후 끝내기. 저장 완료·실패 문구는 버튼 아래 여백을 사용합니다.

## Penpot 배치 완료

로그인한 브라우저를 통해 원본 Penpot 파일의 새 페이지에 5개 SVG 시안을 가져와 정렬했습니다.
기존 페이지와 기존 디자인은 유지했습니다.

- 페이지 이름: Backstreet UI · 메인·플레이·획득·ESC
- 파일: https://design.penpot.app/#/workspace?team-id=ce180602-f36b-8035-8008-cda23f0a1b46&file-id=cd444aaf-0d8c-801b-8008-cda246e18650&page-id=311487d5-89f3-8074-8008-cda65b4d2bec&layout=layers
- 화면 배치: 메인(0,0), 플레이(1280,0), 물(0,780), 녹차(1280,780), ESC(0,1560)
- SVG 텍스트와 UI 도형을 편집할 수 있습니다.
- MCP 접속은 403으로 차단되어 브라우저 UI로 작업했으며, MCP 영구 등록은 하지 않았습니다.
- 인증 토큰은 디자인 파일과 소스에 저장하지 않았습니다.
- Godot 게임에 이 디자인을 적용했습니다. 실제 UI는 `main.tscn`, `Game.tscn`, `ui/backstreet_theme.tres`에 있으며 실행 화면은 `design/godot-applied/`에서 확인할 수 있습니다.
