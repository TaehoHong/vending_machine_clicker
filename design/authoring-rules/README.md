# 디자인 파일 작성 규칙 · 이전 기록 · Penpot에서 제거

**2026-10-20 사용자 지시로 Penpot 작성 규칙 보드와 Text 27개를 제거했다.** 현재 작업 준수사항은 [DESIGN.md](../../DESIGN.md#디자인-작업-준수사항), 실제 페이지 구성과 원본 위치는 [페이지 정리 기록](../page-organization/README.md)을 따른다. 아래 링크·소스·미리보기는 초안 작성 당시 기록이며 현재 Penpot 보드가 아니다. `build.penpot.js`를 현재 파일에 다시 실행하지 않는다.

2026-10-20 사용자 제안 `00 디자인 팔레트(시스템) / 01 게임 화면 / 02 에셋`을 바탕으로 Penpot 원본을 직접 조사하고 작성한 검토용 문서다. 작성 규칙과 추가 페이지 제안은 최종 확정 전 초안이다.

- 작성 전 페이지 6개, 컴포넌트 120개, 등록 색상 0개, 텍스트 스타일 1개.

- 초안에서는 UI 문구의 Text 유지, 원본 컴포넌트 재사용, 검색 가능한 이름, 검토/채택/이전 구분, 원본·출력 동시 검수를 제안했다. 현재 시안의 수치·동작을 새로 확정하지 않았다.

## 산출물·검증

- `build.penpot.js`: Penpot 작성 소스. 지정 파일 ID를 확인하고 같은 이름의 페이지가 있으면 중단하여 중복 생성을 막는다.

- `preview.png`: Penpot 원본 보드 내보내기.
- `penpot-saved.jpg`: 다시 연 편집기의 저장 확인 화면.
- Text 27개, SVG 원시 도형 0개, 보드 밖 텍스트 0개를 확인했다. 기존 컴포넌트·색상·텍스트 스타일 수는 그대로다.
