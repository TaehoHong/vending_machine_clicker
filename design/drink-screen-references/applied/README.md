# 이전 낮 레퍼런스 1번 · 게임 적용본 · 2026-10-19

**최신 채택본은 [Play 픽셀 스타일 통일](play-style/README.md)이다.** 아래의 단순 남색 패널·금색 추가 버튼·Play의 음료수 추가 버튼은 대체되었다. 클릭 전용 정보·자판기 원본 비율·기존 게임 규칙은 유지한다.

사용자 확정 3가지: 1번 낮 디자인 적용, 마우스 클릭 시에만 음료 정보창 표시, 자판기와 정보창 연결선 제거. 구현은 `ui/skill_tree.gd`와 `game.gd`다.

## 현재 화면

- [처음 열었을 때](initial.png): 선택·정보 카드·요약 모두 숨김. 호버로는 열리지 않는다.
- [미해금 음료 클릭](locked-selected.png): 효과·선행 조건·빈캔 추가 버튼. 선택만으로 재화를 소모하지 않는다.
- [획득 음료 클릭](acquired-selected.png): 획득량·기존 게임 효과·누적 능력. 해금 버튼 없음.
- [능력 요약](summary.png): 상단 버튼을 눌렀을 때만 표시.

위 PNG는 Godot 실제 실행 캡처다. 부모 폴더의 AI 레퍼런스 이미지와 구분한다. 창 기본 캡처는 1152×648이며, UI 디자인 공간 1200×760 안의 자판기 원본은 (408,135), 384×576, 2:3이다. 화면 크기에 따라 균일 배율과 중앙 여백을 적용한다. 배경은 현재 게임의 골목 원본을 유지하며 35% 어둡게 한다.

음료 정보·능력 요약은 남색 단순 패널이며 연결선·캔 배지·다음 해금·하단 요약 바는 없다. 능력·음료수 추가 버튼은 통합 화면으로 들어간다. 재진입은 이전 선택을 초기화한다. 카드 X/빈 곳 클릭으로 카드 숨김, ESC/닫기로 플레이 복귀. 기존 능력 계산과 해금 비용은 변경하지 않았다. 예를 들어 현재 게임의 이온음료는 발견 골드 +2이며 생성 레퍼런스의 확률 증가 문구로 바꾸지 않는다.

## 검증

`tests/drink_screen_test.gd` 통과: 실제 마우스 이동/클릭으로 호버 무반응·클릭 선택·재진입 초기화, 선행 조건과 잔액, 선택 시 미차감, 5개 정확 차감·중복 해금 방지, 획득량·누적 효과, 요약 토글, ESC, 작은 창에서 카드·15종 영역이 화면에 들어오는지 확인했다. headless 및 실제 D3D12 실행 모두 통과했다.

기존 `tests/drink_unlock_screen_test.gd`는 통합 UI의 새 규칙에 맞춰 갱신했고 통과했다. `tests/purchase_price_test.gd`의 5% 복리·구매 중복 방지·저장·로드 회귀 검증도 통과했다. 과거 별도 능력 목록 배치에 종속된 이전 테스트는 이번 UI 검증 기준으로 사용하지 않았다.
