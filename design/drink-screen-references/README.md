# A 배치 기반 완성 화면 레퍼런스 3종 · 미채택 · 2026-10-19

후속 사용자 선택으로 **1번 낮 버전을 게임에 적용했다.** 클릭 전용 정보창·연결선 제거를 반영한 [실제 실행본과 최신 편집 원본](applied/README.md)이 현재 기준이다. 아래 PNG는 선택 전 생성 레퍼런스이며 연결선이 있는 원본 이미지도 과거 기록으로 보존한다.

최신 A 배치와 현재 게임 자판기 원본을 기반으로 완성 화면의 분위기를 비교한다. 세 가지는 시간대 표현을 비교하는 디자인 제안이며 게임에 낮밤 시스템을 추가하거나 구현한 것이 아니다. 게임 코드와 확정 기획은 변경하지 않았다.

| 방향 | 완성 이미지 | 편집용 배치·색상 원본 |
|---|---|---|
| A 낮 · 기존 게임과 연결 · 추천 | [PNG](a-daylight.png) | [SVG](a-daylight.svg) |
| B 노을 · 따뜻한 골목 | [PNG](b-dusk.png) | [SVG](b-dusk.svg) |
| C 밤 · 자판기와 카드 강조 | [PNG](c-night.png) | [SVG](c-night.svg) |

- 완성 PNG는 built-in imagegen으로 생성했다. [프롬프트](prompts.json). 현재 A 실제 자판기 미리보기·자판기 원본·플레이 배경을 참조했다.
- [원본 생성 소스](build_sources.py), [전체 비교 SVG](editable-gallery.svg). 기존 배경·자판기 아트를 그대로 포함하고 패널·문구·배색을 직접 편집할 수 있다. AI의 노을/밤 재조명 픽셀 아트 자체를 벡터화한 파일은 아니며, 해당 배경 표현은 PNG로 검토한다.
- 편집 원본 기준 자판기는 (408,135), 384×576, 2:3이다. 이미지 생성본의 치수는 근사치이며 게임 크기를 임의 변경하는 근거로 쓰지 않는다.
- 비용은 선택 카드에서만 표시하며 자판기 아래 캔 배지를 두지 않는다. 하단 능력 요약 바·다음 해금 칸·큰 고정 오른쪽 박스는 없다. 능력 요약은 상단 버튼이다.
