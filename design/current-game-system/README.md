## 재사용 범위

- `Clicker / CurrentGame / Core`: 기존 라이브러리 색상 중 반복 사용되는 16개 역할. 외곽·면·빛·그늘, 글자·선택, 액션 4상태, 가격·진행·알림을 구분한다. 기존 색상 ID를 유지했다.
- `Clicker / CurrentGame / Type / Core`: 제목 30, 구획 제목 23, 본문·조작 18, 보조 정보 16, 능력 버튼 26, 골드·가격 28. Cafe24 PRO UP Regular를 사용한다. 28px 가격 스타일은 기존 라이브러리를 재사용한다.
- `Type / Specific`: 현재 구현에 필요한 나머지 15개 크기를 보존한다. 화면 전용 값을 공통 기본값으로 확장하지 않는다.
- `Clicker / CurrentGame / Play`: 능력·청록 액션 버튼 4상태, 음료 상세, 수집 목표, 재화 HUD, 가격판. 화면 예시는 연결 인스턴스이며 네이티브 Text를 편집한다. 기존 HUD 아트 컴포넌트 `d7a10464-8e4d-803c-8008-ceb3277ad90a`를 재사용한다.
- 버튼의 면·그림자·Text는 크기 변경 제약을 적용한다. 일반 조작은 150×60·18px, 능력은 170×64·26px의 현재 구현 예시다. 외곽 2px/3px와 프레임 9분할 L14/T14/R14/B18을 구분한다.

`90`은 현재 메뉴·일시정지의 별도 테마와 화면 전용 크기다. `참고 / 기존 UI 검토안`, `참고 / 가격 버튼 A · 별도 원본`은 비교용 원본으로 아래에 구분했다. 별도 HUD A 채택 보드는 해당 작업의 원본을 우선하며 이 정리에서 수정하지 않았다.

## 상태·피드백과 검수

`03`에서 해금 가능과 빈캔 부족을 색상·문구로 함께 비교한다. 재화·가격은 연결 마스터를 조합했다. 능력 획득 알림은 `ui/ability_toast.gd`의 510×94, 제목 21px·본문 18px, 1.0초 유지 후 0.6초 알파 소멸을 표시한다. 예시 음료명·효과·횟수는 시각 견본이다.

2026-10-20 Computer Use로 최종 편집 후 파일을 다시 열어 보드 렌더링, Cafe24 글자, 클리핑, 연결된 상세·버튼·HUD 예시를 확인했다. 겹친 안내 레이어와 버튼 인스턴스를 제거했다. 수집 목표의 사용 가능한 복원 마스터는 보드 02의 `9a779784-0f70-804d-8008-d10bebded89b`, 컴포넌트 ID는 `9a779784-0f70-804d-8008-d10bfd5355f7`이다.

남은 제한: 이전 QuestPanel 컴포넌트 `b3f38c37-8163-8042-8008-d1013cd498b1`는 라이브러리에 빈 항목으로 보이며 UI 삭제 결과를 확인하지 못했다. 새 작업은 위 복원 마스터를 사용한다. 맑은 고딕 400·700은 Penpot 미설치로 안내용 Noto Sans KR과 구분한다. 다국어 대체 글꼴 정책은 미확정이다.

게임 동작·적용 에셋·기획은 변경하지 않았다. 이번 검수는 Penpot 편집기 검수이며 Godot 실행 테스트가 아니다. 작업 준수사항은 [DESIGN.md](../../DESIGN.md)에만 두고 Penpot 안에는 작성 규칙 보드를 만들지 않는다.
