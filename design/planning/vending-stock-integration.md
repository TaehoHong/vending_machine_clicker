# 자판기 진열 / 확정 음료 15종 연결

- 실제 자판기: images/vending_approved_15.png (생성해 Penpot에 추가한 이미지 원본).
- 음료 단품: images/drinks/approved/*.png (Penpot의 확정 15종 컴포넌트에서 투명 PNG 일괄 내보내기).
- 구매 목록과 진열은 game.gd의 purchasable_drinks()를 공통 기준으로 사용한다.
- 잠긴 음료의 영역은 셰이더로 빈 선반으로 표시하며 해금 시 해당 칸의 원본 음료가 즉시 표시된다. 다른 진열칸과 본체는 유지된다.
- 초기 구매 가능 음료: 물, 녹차.
- 이후 이온음료부터 빈캔을 사용해 가지를 해금하며, 구매 목록·자판기·능력 목록에 함께 반영된다.
- 기존 저장 인덱스를 보존했다. 기존 환타 항목은 황금음료로, 스프라이트 항목은 레몬라임 소다로 표시한다. 기존 수집 개수와 해금 상태는 이어진다.
- 이번 작업은 15종의 구매·수집·해금·진열 연결이다. 기존 음료 능력 계산은 유지했고, 새로 추가한 6종은 빈캔 수집을 연결했다. Notion의 15종 고유 능력·피버·황금음료 스테이지 전환 기획 전체를 구현한 변경은 아니다.

## 임시 해금 비용과 가지

사용자의 15종 동기화 승인에 따라 임시로 설정한 비용과 순서이며 확정 기획 수치가 아니다.

| 음료 | 선행 음료 | 빈캔 비용 |
|---|---|---:|
| 이온음료 | 없음 | 5 |
| 보리차 | 이온음료 | 8 |
| 사과 주스 | 이온음료 | 8 |
| 진저에일 | 보리차 | 10 |
| 레모네이드 | 사과 주스 | 10 |
| 레몬라임 소다 | 진저에일 | 12 |
| 복숭아 주스 | 레모네이드 | 12 |
| 오렌지 주스 | 레몬라임 소다 | 15 |
| 비타민 음료 | 복숭아 주스 | 15 |
| 멜론 소다 | 오렌지 주스 | 20 |
| 콜라 | 비타민 음료 | 20 |
| 에너지 드링크 | 콜라 | 25 |
| 황금음료 | 에너지 드링크 | 30 |

## 검증

- vending_display_test.gd: 초기 2종, 선행 조건, 전체 15종 해금, 빈캔 비용, 진열 마스크와 구매 목록 일치, 각 구매 결과 이미지, 저장 후 진열 복원.
- expanded_skills_test.gd: 전체 가지와 기존 능력 계산, 구매 결과, 저장 복원.
- Godot 화면 캡처: 초기 2종 / 이온음료 해금 직후 / 전체 15종 / 트리 상하단 / 에너지 드링크 구매 결과.
