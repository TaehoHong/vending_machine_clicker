## 최신 적용 · 이름표 UI 정리

2026-10-18 이름표가 자판기 그림과 어울리지 않는다는 사용자 피드백을 반영했다. 01 시트의 기존 이름표 도형·텍스트 30개를 직접 수정했다. 밝은 종이 띠를 80.2×18px의 짙은 금속 명판으로 바꾸고, 안쪽 1px 테두리와 Cafe24 PRO UP 11.5px 중앙 정렬 텍스트로 통일했다. 기본 글자는 크림색, 선택한 물은 금색 글자·테두리이며 이름의 ‘선택’ 문구는 제거했다. 음료와 본체의 원본 연결 및 조립 그룹은 유지했다.

15개 이름의 실제 렌더링 폭을 명판과 비교해 모두 안에 들어가는 것을 확인했다. 기록은 `label-polish-verification.json`, 현재 검수 화면은 `../review/ability-unlock/nameplates-v6-preview.png`와 `nameplates-v6-editor.png`다. 아래 구조 수정 검수본은 이름표 변경 전 이력이다.

## 본체 통합 및 이동 구조 수정 · v5

사용자가 02 시트의 `에셋` 보드(`af2aed71-3cfe-80ea-8008-ceb0d537ce15`)를 원본으로 지정하고 01 시트 능력해금 창에 적용하도록 요청했다. Computer Use로 기존 보드 ID를 유지하며 다음과 같이 반영했다.

- 지정 B의 기존 상품 영역을 SVG 클리핑에서 제외하고 빈 진열 배경과 함께 단일 PNG로 렌더링했다 (`body-b-empty.png`, 350×525). 원래 통합 B 원본은 보존하고, 새 빈 본체를 02 시트의 별도 원본 컴포넌트로 등록한 뒤 능력해금 창에 연결 복사본으로 배치했다.
- 일본풍 골목 배경·일시정지 버튼의 원본 연결과 기존 Cafe24 PRO UP 텍스트를 유지했다.
- `음료수 에셋`의 최신 음료 15종 원본과 연결하고, 병·캔의 비례 및 기존 5×3 선반 기준선에 맞췄다. 선택·미획득 표식과 능력 설명은 유지했다.
- 이전 적용의 기본 음료가 박힌 B 복사본과 외부 크림색 가림판 그룹은 삭제했다. 새 본체 PNG에는 기본 음료 픽셀이 들어 있지 않다.
- 자판기 상위 그룹의 직접 자식은 본체·버튼·표시창 묶음과 상품 15종 묶음 두 개다. 음료는 묶음 안에서 개별 연결 복사본으로 유지된다.
- 상태 예시의 물·콜라·레모네이드도 동일 원본의 연결 복사본으로 교체했다.
- 자판기를 X +100, Y +40 이동했을 때 하위 도형 198개의 화면상 이동량이 모두 일치했으며 원위치로 복원했다. 상품 묶음을 숨기면 기본 음료 없이 빈 진열창이 보인다. 저장된 파일의 전체 미리보기에서도 새 본체와 음료 15종을 확인했다.

현재 적용 ID는 `original-components-manifest.json`, 구조 및 이동 검사는 `structural-fix-verification.json`에 있다. 검수 캡처는 `../review/ability-unlock/main-structural-fix-preview.png`, `main-structural-fix-editor.png`, `machine-products-hidden.png`, `machine-move-test.png`다. `main-original-components-*`는 가림판 방식이 남아 있던 이전 이력으로 현재 검수본이 아니다. 아래 v3 SVG·생성 소스도 과거 이력이며 현재 편집 원본은 Penpot의 동일 보드다.

- 1600×900 화면. 사용자 후속 지시에 따라 가로형 메뉴 패널을 세로형 실제 자판기 구조로 수정했다. 기존 자판기 B의 외장·3단 진열·결제부·배출구·다리를 기준으로 네이티브 도형을 구성했다.
- 카드형 타일을 제거하고 연속된 조명 진열창과 선반에 승인된 음료 15종을 5×3으로 배치. 외형은 `design/v9/exports`의 개별 PNG를 재사용.
- 상품 아래 실제 누름 버튼·상태 LED로 선택·해금 상태를 표현하고, 미해금 상품에는 흐린 아트와 잠금 아이콘을 표시했다. 오른쪽에는 동전 슬롯·지폐 리더·반환 레버를, 아래에는 깊이감이 있는 배출구와 통풍구·받침 다리를 배치했다. 결제부는 외형이며 추가 구매 동작을 만들지 않는다.
- 본체에 내장된 작은 표시창에 선택한 음료의 이름, 효과, 획득 횟수를 표시. 능력은 구매 성공 시 즉시 적용되므로 별도 사용 버튼을 추가하지 않음.
- 별도 상태 보드에서 해금됨·미해금·최대 강화 상태와 조작 의도 정리.
- 원본 러프를 보존한 채 옆으로 이동. 기존 메인과 에셋 페이지 내용은 수정하지 않음.

효과, 획득 횟수, 강화 한도, 8/15 진행도는 시안 예시다. 물의 골드 증가·레모네이드 한도 등은 PRODUCT.md의 제안 배정표를 참고했으며 확정 규칙으로 승격하지 않았다. 황금음료 효과, 피버 세부 규칙, 한도 이후 보상은 정하지 않았다. 키보드 이동·Enter 선택은 구현 제안이다. 화면 조작은 정적 시안이며 프로토타입 연결이나 게임 동작을 구현한 것은 아니다.

## Astra 리뷰 반영 v3 · MCP 적용 완료

2026-10-18 사용자의 요청으로 Astra 리뷰를 반영했다. 새 산출물은 `main-v3.svg`, `states-v3.svg`, `geometry-v3.json`, `apply-v3.penpot.js`다. 사용자가 새로 제공한 임시 연결로 MCP를 복구해 기존 메인·상태 보드 ID를 유지하며 적용했다. `execute_code` 결과로 메인·상태 보드와 상품 15개 반영을 확인했다. 연결 토큰은 저장하지 않았다. 사용자가 Penpot을 Computer Use로 열지 말라고 지시한 이후에는 MCP만 사용했다.

- 외장: 기존 B를 참조한 built-in ImageGen 아트 `cabinet-b-empty-v3.png`. 원본 B와 승인된 음료 15종은 유지했다. 정확한 생성 프롬프트는 `v3-prompt.txt`에 보존.
- 진열: 간판·LCD·반복 테두리의 비중을 줄이고 유효 음료 높이를 큰 병 103px, 팩·캔 84–92px, 작은 비타민 병 80px로 배치했다. 이전 화면은 약 57px였다. 원본 이미지의 알파 경계를 측정해 물리적인 선반 바닥에 맞췄으며 음료 픽셀은 수정하지 않았다.
- 깊이: B 스타일의 금속 선반·도장 마모·깊은 배출구·다리를 사용하고 바닥 접지 그림자와 돌출형 상품 버튼을 추가했다.
- 상태: 획득 상태와 선택을 분리했다. 미획득 상품 외형을 읽을 수 있게 유지하고 잠금과 최대 강화 표식을 같은 위치에 작게 표시했다. 모든 음료 버튼으로 설명을 선택하는 디자인이며 직접 구매·사용 동작은 없다.
- 정보: LCD에 현재 누적 효과와 획득 횟수를 구분했다. Astra 재검토에서 지적한 작은 용기 비례·선택 표시·LCD 가독성까지 한 번에 보정했다.

초기 로컬 검수본: `../review/ability-unlock/main-v3-local.png`, `states-v3-local.png`. 이후 Cafe24 PRO UP 적용까지 마친 두 보드를 MCP로 직접 내보내 `main-cafe24-penpot.png`, `states-cafe24-penpot.png`로 보존했다. 두 이미지에서 음료 15종과 텍스트 배치, 글자 잘림이 없는 것을 확인했다. 이전 Penpot 시안은 `machine-v2-before-astra.png`에 보존했다. 새 UI의 게임 동작은 구현하지 않았다.

## 글꼴 요청 · Cafe24 PRO UP

사용자가 능력 해금 화면 글꼴을 Cafe24 PRO UP으로 지정했다. 설치된 `Cafe24PROUP.ttf`의 정식 family는 `Cafe24 PRO UP`, style은 `Regular`다. `build_v3.py`와 `apply-v3.penpot.js`, SVG는 이 글꼴로 갱신했다. `apply-font.penpot.js`는 기존 메인·상태 보드의 텍스트에만 글꼴을 적용하고 다른 속성은 유지한다. Penpot에 해당 family가 없으면 변경 없이 반환한다. 로컬 글꼴로 측정한 모든 텍스트가 기존 폭 안에 들어가는 것을 확인했다. 사용자의 팀 글꼴 등록·재연결 후 목록에 글꼴이 나타나 두 보드의 텍스트 40개에 MCP로 적용했다. 후속 조회에서 40개 모두 `custom-32acebab-c2dc-8059-8008-ceedca013d66` / `Cafe24 PRO UP`을 사용하는 것을 확인했다. Penpot 직접 내보내기 검수본은 `main-cafe24-penpot.png`, `states-cafe24-penpot.png`다.
