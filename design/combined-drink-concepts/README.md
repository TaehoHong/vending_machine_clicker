[반영 확인](penpot-synced.png). PNG는 로컬 완성 분위기 레퍼런스로 보관한다.

모든 수치·비용·해금 상태는 시안 예시다. 생성 이미지의 생수/골드/레몬음료 표기는 실제 적용 시 확정 명칭 물/황금 음료수/레모네이드로 정리하며 B 하단 중복 음료 썸네일은 제거한다. A의 미확정 아이템 발견 확률 문구는 채택 시 실제 누적 능력으로 교체한다. C의 ‘해금한 음료만 적용’ 문구는 ‘획득한 음료의 누적 효과’로 정리한다. 최종 실제 능력은 PRODUCT.md와 최신 사용자 확정 규칙을 따르며, 현재 코드와의 수치 차이를 이 디자인 작업에서 확정하지 않는다.

비교 제안이므로 PRODUCT.md·Notion의 확정 기획은 변경하지 않았다. 통합 적용과 진입 버튼 정리는 사용자 선택 후 진행한다.
