# 밝은 카드형 · 동일 크기 패널 수정 · 2026-10-19

> 2026-10-20 페이지 정리: 현재 원본 위치는 [페이지·에셋 정리 기록](../../page-organization/README.md)을 따른다. 아래 Y 좌표·페이지 이름·생성 manifest는 작성 당시 기록이며, Penpot 링크는 현재 위치로 갱신했다.

이후 사용자 피드백으로 미채택된 기록이다. 최신 방향은 [중앙 자판기 + 작은 정보 카드 배치도](../../drink-layout-wireframes/README.md)이며 아래 확정·현재 표기는 이 시안 제작 당시 기록이다.

최신 사용자 요청을 반영한 현재 시안이다. 이전 compact의 면적 1/3 축소, 비용 두 줄 배치, 하단 요약·다음 해금 표시는 폐기된 방향으로 보존한다. 게임 코드는 변경하지 않았다.

1. 음료 하단의 이름 **오른쪽**에 빈캔 아이콘과 필요 수량을 같은 줄로 표시한다.
2. 맨 아래 현재 적용된 능력 요약 영역을 제거하고 자판기를 확대한다.
3. 오른쪽 외곽 박스는 확대된 자판기와 같은 크기로 맞추고 상하 선을 정렬한다.
4. 박스 내부 아이콘과 글자는 작게 줄여 상단에 모으고 여백을 둔다.
5. 다음 해금 영역과 그 안의 음료 미리보기·해금 버튼을 모두 제거한다.

- [완성 분위기 PNG](preview.png): built-in imagegen 편집, [주 프롬프트](prompt.txt), [내부 콘텐츠 축소 보정](content-size-prompt.txt).
- [편집용 구조 SVG](layout.svg), [재생성 소스](build_source.py). 도형·문구·비용을 수정할 수 있으며 음료는 구조용 자리표시 도형이다. PNG 전체 픽셀 아트를 벡터화한 소스는 아니다.
- 구조는 1672×940, 좌측 (60,150) 750×750, 우측 (860,150) 750×750이다. 오른쪽 보유 빈캔 23px, 이름24px, 획득량18px, 상태14px, 효과20px, 아이콘39×65로 설계했다. 실제 게임 해상도 적용은 별도다.
- 생성 PNG는 완성 분위기용이며 좌우 너비가 약간 다를 수 있다. 정확한 동일 크기는 SVG를 기준으로 한다. 긴 음료명은 한 줄 유지를 위해 짧은 표기를 사용하며 실제 적용 시 툴팁으로 전체 이름을 제공할 수 있다(제안).
- 빈캔 비용·능력 수치는 임시 예시다. 비용은 이전과 동일하게 현재 카탈로그 값을 참고했으며 밸런스를 확정하거나 게임 데이터를 수정하지 않았다.
