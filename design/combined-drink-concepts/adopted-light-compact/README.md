# 밝은 카드형 선택 · 축소 수정 · 2026-10-19

이전 기록: 최신 요청으로 [동일 크기 패널 수정본](../adopted-light-aligned/README.md)이 우선한다. 비용 두 줄·우측 축소·하단 요약·다음 해금 배치는 현재 방향이 아니다.

사용자 선택: 오른쪽 변형 1번 밝은 카드형. 음료 하단에 빈캔 비용 표시를 추가하고 오른쪽 설명 창을 대폭 축소한다. 게임 적용 전 디자인 시안이며 이 선택은 이전 미채택 비교 기록보다 우선한다.

- [완성 분위기 PNG](preview.png): built-in imagegen으로 편집. [초기 프롬프트](prompt.txt), [축소 보정 프롬프트](refinement-prompt.txt).
- [편집용 구조 SVG](layout.svg), [재생성 소스](build_source.py). 패널·텍스트·비용·음료 자리표시 도형이 편집 가능하다. PNG 픽셀 아트를 완전히 벡터화한 소스는 아니다.
- 편집 원본에서 오른쪽 창 면적은 기존 510×460에서 350×220으로 약 1/3이다. 가로·세로 각각 1/3로 줄인다는 뜻으로 해석하지 않았다. 완성 PNG는 시각 레퍼런스이며 픽셀 치수의 기준은 SVG다.
- 왼쪽의 15종 배열을 유지하고 이름과 비용을 같은 하단 라벨에 배치했다. 좁은 폭에서 가독성을 위해 이름과 빈캔 비용은 두 줄이다. 물·녹차는 기본이다.
- 코드의 현재 테스트용 비용 참조: 보리차8, 이온음료5, 사과8, 진저10, 레모네이드10, 라임12, 복숭아12, 오렌지15, 비타민15, 멜론20, 황금30, 콜라20, 에너지25. 새 밸런스 확정이 아니다.
- 생성 PNG의 이온음료 하단 숫자를 마지막 편집에서 5로 맞췄다. 실제 적용 시 비용은 게임 데이터에 연결한다. 하단의 기존 아이템 발견 확률 문구는 미확정 레퍼런스이므로 실제 능력으로 대체한다.
