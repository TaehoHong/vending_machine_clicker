# v4 · Click the Button 기준 메인 플레이 재설계

사용자 지정 레퍼런스: https://store.steampowered.com/app/3946950/Click_the_Button/

제작 상태: 사이드 패널 없는 메인 1보드, 1600×900. 입력·보상·구매의 모션과 전후 상태는 아래에 설계했으며 이번 메인 보드에 게임 로직이나 연속 입력 프로토타입을 구현한 것은 아니다.

2026-10-18 아트 수정: 수동·자동 자판기를 정면 스프라이트로 교체한다. 일본풍 골목길의 중앙 벽 앞에 자판기를 두고, 아래 포장 바닥을 동전 수색 영역으로 사용한다. 기존 HUD·가격·강화·해금 배치와 모션 구상은 유지한다.

직접 확인한 실제 스크린샷: 메인 플레이, 강화 트리, 룰렛 결과. 메인은 큰 중앙 클릭 대상, 필드에 나타나는 보상, 모서리 재화 HUD와 강화 진입으로 구성된다. 강화 화면을 플레이 필드에 상시 펼치지 않는다. 굵은 외곽선·선명한 픽셀 스프라이트·큰 수치로 조작과 보상을 강조한다.

이번 범위는 메인 화면 한 장과 핵심 입력의 전후 상태 검토다. 이전 v3의 15개 보드를 기준으로 수를 늘리지 않는다. 다른 페이지는 보존한다.

## 확정 규칙

프로젝트 AGENTS.md 지시에 따라 PRODUCT.md를 다시 읽었다. 연결된 Notion 도구는 해당 페이지에 404를 반환했으므로 최신 Notion 원문을 다시 확인했다고 간주하지 않는다.

- 자판기 밑 클릭 → 동전 획득 → 능력 구매 시도.
- 성공 즉시 능력치 증가. 별도의 음료 사용 버튼이나 소모품 퀵슬롯을 만들지 않는다.
- 남은 빈캔·빈 용기 등은 해금 재료다. 해금 시 현재 보유량을 소모한다.
- 자동 자판기와 쓰레기통이 주는 물품은 능력 구매로 처리하지 않는다.
- 가격·확률·시간·조건은 확정 전 예시다.

## 메인 정보와 위치

| 요소 | 표현과 조작 |
|---|---|
| 자판기와 바닥 | 화면 중앙의 큰 게임 오브젝트. 수색 위치는 기계 바로 아래이며, 설명 패널로 덮지 않는다. |
| 골드·물품 | 좌상단 작은 HUD. 가격과 비교할 수 있는 큰 숫자, 용도별 아이콘. |
| 수색 피드백 | 클릭 위치에 80ms 이내 반응. 진행 표시도 이 근처에 작게 두고 입력을 막지 않는다. |
| 능력 구매 | 기계 옆의 가격 버튼. 구매 가능·골드 부족을 구분한다. |
| 자동 자판기·회수 | 설치된 기계와 바닥의 물품으로 표현. 회수 가능한 물품을 강조한다. |
| 강화·해금 | 우하단 진입 버튼. 선택할 때 관련 화면을 연다. |
| ESC | 우상단 작은 버튼. |

## 핵심 전후 상태

1. 대기: 가격, 보유 골드, 자판기 밑 클릭 위치가 보인다.
2. 동전 획득: 마지막 클릭 → 동전 튀기기 → 금액 팝업 → HUD 반영. 연속 입력을 받는다.
3. 구매 성공: 골드 차감 → 배출 반응 → 능력 증가와 물품 획득을 같은 자리에서 표시한다. 별도 사용·보관 선택은 없다.
4. 꽝: 비용은 차감되며 능력 상승과 성공 물품은 표시하지 않는다.

## 모션

- 입력 60–80ms 눌림, 획득 동전 180ms 튀어오름, 금액 표시 약 450ms 후 HUD 이동.
- 구매 100ms 점등 → 160ms 짧은 기계 반응 → 180ms 배출 → 효과 600ms 강조.
- 연출 중 반복 입력을 막지 않고 결과는 각각 갱신한다. 화면 흔들림은 약하게 제한한다.
- 강화 진입은 160–200ms, 닫기는 더 짧게 한다. 모션 줄이기는 흔들림과 입자를 제거한다.
- Penpot의 정적 전후 상태와 전환은 실제 게임의 타이머·확률·재화 누적 구현을 의미하지 않는다.

## 검증 기준

마우스를 움직이지 않고 반복 수색할 수 있어야 한다. 가격·보유 골드·다음 행동을 즉시 찾을 수 있어야 한다. 구매 성공부터 능력 적용까지 추가 조작이 없어야 한다. 재화와 물품을 혼동하지 않고, 자동 회수로 능력이 증가하지 않아야 한다.
