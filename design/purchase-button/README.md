# 가격 버튼 A 기본형

[공통 버튼 원본](https://design.penpot.app/#/workspace?team-id=ce180602-f36b-8035-8008-cda23f0a1b46&file-id=cd444aaf-0d8c-801b-8008-cda246e18650&page-id=490e660f-738c-80e7-8008-d0f0d410a6b5&layout=layers&board-id=d9c1a69c-6a27-809e-8008-d107e6137aa4)에서 재사용한다. 컴포넌트 ID는 `8e4548c6-4cd1-8076-8008-ceef6c094af7`이며 [등록 정보](penpot-manifest.json)에 연결했다.

144×56, Cafe24 PRO UP Regular, 금액만 표시한다. Penpot의 금액은 편집 가능한 네이티브 Text다(28px, 외곽 2.2px). 기존 컴포넌트 ID를 유지하고 연결 화면 25곳에 반영했다. `price-only-v3.svg`와 기존 PNG는 이전 출력이며 현재 원본을 대체하지 않는다. 100 G는 시각 예시이며 게임 구매 가격을 확정하지 않는다.

상태·출력 규격은 [HUD A 안내](../hud-buttons/README.md)를 따른다. 이전 비교 시안과 검수 이미지는 현재 채택본·게임 적용의 근거로 사용하지 않는다.
