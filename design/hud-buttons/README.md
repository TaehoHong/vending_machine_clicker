# HUD 버튼 전체 시안 · 승인 대기

사용자가 전체 버튼을 먼저 시안으로 보고 승인한 뒤 에셋 시트에 반영하도록 요청했다. 이 폴더는 검토용이며 Penpot 쓰기·게임 코드 적용은 하지 않았다. 기존에 승인해 등록한 `100 G` 가격 버튼은 유지한다.

## 검토 이미지

- `01-hud.png` / SVG: 지도·능력·강화·자동화·메뉴 5종과 각 용도.
- `02-common.png` / SVG: 뒤로·닫기·이전·다음, 자동 자판기·쓰레기통 탭, 골드·재료 비용의 충족/부족 상태, 계속하기·설정·타이틀.
- `03-states.png` / SVG: HUD 5종의 기본·호버·눌림·비활성·키보드 포커스.
- `browser-proof-*.png`: 실제 로컬 브라우저에서 확인한 세 시트.
- `index.html`: 세 시트를 전환하며 클릭·키보드·탭 선택 반응을 보는 로컬 시안. 현재 `http://127.0.0.1:8878/`에도 같은 내용을 제공한다.

## 외형과 범위

기존 A 픽셀 아케이드의 파란 면, 굵은 외곽선, 계단형 모서리와 입체 밑면을 이어 쓴다. HUD 원본은 176×64이며 보드에는 1.2배로 보여준다. 아이콘은 자체 제작한 32×32 벡터 14종이다. 게임 글자는 `ui/fonts/Cafe24PROUP.ttf`의 실제 글리프 윤곽선을 사용해 환경에 따른 대체 글꼴을 피했다. 안내 문구는 게임 에셋이 아니라 검토용 설명이다.

호버 90ms, 눌림 60ms·4px 이동, 복귀 100ms다. 입력 영역은 고정하며 비활성 버튼은 HTML disabled로 입력을 막는다. 선택 탭은 밝은 면과 하단 금색 표시를 함께 쓴다. 모션 줄이기에서는 전환을 끈다. 비용은 금액·재료 아이콘·수량만 표시하며 액션 문구를 넣지 않는다. 모든 금액과 수량은 예시다.

수색·펀치·음료 사용·수동 피버 실행 버튼이나 새 게임 화면은 추가하지 않았다. 지도 상세·강화 상세 등 실제 게임 기능은 이 시안에서 실행되지 않는다.

## 소스

`components.json`이 목록과 승인 상태, `build.js`가 벡터·PNG·인터랙션 생성 소스다. `font-outlines.swift`는 원본 글꼴에서 15개 라벨의 윤곽선을 `font-outlines.json`으로 추출한다. `exports/`에는 18개 항목 × 5상태의 SVG 90개를 보존한다. SVG에는 포커스 선을 위한 6px 여백이 있으므로 표시한 버튼 본체 크기와 파일 캔버스 크기를 구분한다.

브라우저에서 지도 클릭, 능력 Enter, 설정 Space 입력과 자동 자판기↔쓰레기통 선택 상태 변경을 확인했다. 골드·재료 부족 버튼의 disabled 상태, 세 시트의 외형과 90개 SVG 파싱을 확인했다. 검수는 로컬 시안 범위이며 게임 구현 검증이 아니다.

승인 후 기존 Penpot **02 · 에셋 라이브러리** 안에서 MCP로만 반영한다. 새 페이지를 만들지 않는다. 현재 폴더의 모든 새 항목은 `preview-awaiting-user-approval` 상태다.
