# Arcade Pop 음료 아트

사용자가 선택한 B / Arcade Pop 방향으로 생성한 음료 9종입니다.
`arcade_pop_atlas.png`는 투명 배경 원본이며 각 `*_pop.tres`가 AtlasTexture 영역을 지정합니다.
획득창, 능력창, 스킬 트리가 동일한 리소스를 사용합니다.

배치: 물 / 녹차 / 이온음료 → 비타민 / 사과 / 오렌지 → 콜라 / 환타 / 스프라이트.
이전 SVG는 비교 및 복구를 위해 보존합니다.
생성 이미지의 패키지 표기는 장식이며, 게임 내 음료 이름과 효과는 기존 카탈로그를 따릅니다.
