# Cafe24 PRO UP

승인된 A 픽셀 버튼에 사용한 Cafe24 PRO UP Regular 원본이다. 게임 전체 글꼴을 교체하지는 않는다.

- 파일: `Cafe24PROUP.ttf` — 수정하지 않은 원본, 577900 bytes.
- 저작권: Cafe24 Corp. 원본 글꼴의 copyright 메타데이터와 함께 보존한다.
- 배포처: https://fonts.cafe24.com/
- 파일 출처: https://raw.githubusercontent.com/fonts-archive/Cafe24PROUP/main/Cafe24PROUP.ttf
- 배포 안내 원문: `Cafe24PROUP-LICENSE.md`.
- SIL OFL 1.1 전문: `OFL.txt`. 본문 출처 https://openfontlicense.org/documents/OFL.txt

Penpot에서 확인한 사용자 글꼴 ID는 `custom-32acebab-c2dc-8059-8008-ceedca013d66`다. 가격 버튼 텍스트 스타일은 `Clicker/UI/Pixel/Price · Cafe24 PRO UP · 28`이다.

## Noto Sans KR

채택된 정보 카드의 설명 본문에 사용한다. 제목·수량·버튼의 Cafe24 PRO UP은 유지한다.

- 파일: `NotoSansKR.ttf` — Google Fonts의 `NotoSansKR[wght].ttf` 원본.
- 출처: https://github.com/google/fonts/tree/main/ofl/notosanskr
- 라이선스: SIL OFL 1.1, 원본 전문은 `NotoSansKR-OFL.txt`에 보존한다.
- 공통 `play_theme.tres`의 `InfoBody`가 가변 글꼴의 굵기 400을 사용한다.
